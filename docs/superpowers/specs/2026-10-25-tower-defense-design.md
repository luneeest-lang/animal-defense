# 동물 타워 디펜스 게임 설계

- 작성일: 2026-10-25
- 상태: 검토 대기
- 저장소: 별도 저장소(가칭 `tower-defense`)에 구현한다. 이 문서는 이동 전까지 이 저장소에 둔다.

## 1. 목표

방문자가 브라우저에서 바로 즐기는 가벼운 2D 경로형 타워 디펜스 게임을 만든다. 광고 수익에 도움이 되도록 로딩이 가볍고, 모바일 터치와 PC 마우스를 모두 지원한다. 서버와 로그인 없이 정적 파일로 배포한다.

## 2. 범위

**포함**
- 맵 3개 (처음에는 1개만 열림, 클리어하면 다음 맵 열림)
- 동물 타워 5종, 타워별 업그레이드 3단계
- 적 5종과 보스
- 15개 웨이브, 한 판 약 8~12분
- 최고 기록 저장 (맵별 최고 웨이브, 별 1~3개, 열린 맵)
- PC와 모바일 조작, 일시정지, 배속(1x, 2x)

**제외 (첫 버전)**
- 사운드
- 계정, 랭킹 서버
- 타워 목표 선택 옵션
- 영구 강화, 스테이지 트리

## 3. 접근 방식

순수 JavaScript와 Canvas를 쓴다. 빌드 도구, 프레임워크, npm 패키지가 없고, 브라우저가 ES 모듈을 직접 불러온다. 로딩이 가볍고 의존성 관리가 필요 없기 때문이다. 게임 엔진(Phaser)과 TypeScript + Vite는 이 규모에 과해서 쓰지 않는다. 게임 규칙을 화면과 분리해 두므로 나중에 엔진으로 옮기기도 어렵지 않다.

## 4. 구조

게임 규칙(`core/`)은 화면을 모르고, 화면(`ui/`)은 규칙의 상태를 읽어서 그리기만 한다. 그래서 규칙은 Node로 테스트할 수 있다.

```
tower-defense/
├─ index.html
├─ css/style.css
├─ assets/animals/       # 동물 5종 SVG (기본 + 업그레이드 1~3단계)
├─ js/
│  ├─ main.js            # 시작점, 게임 루프(requestAnimationFrame)
│  ├─ core/              # 화면 없는 순수 로직
│  │  ├─ game.js         # 한 판의 상태: 골드, 생명, 웨이브 진행
│  │  ├─ path.js         # 경로 위 위치 계산, 설치 가능 칸 판정
│  │  ├─ towers.js       # 목표 선택, 발사, 업그레이드, 판매
│  │  ├─ enemies.js      # 이동, 피해, 상태 이상
│  │  └─ waves.js        # 웨이브 스케줄
│  ├─ data/              # 숫자와 정의만 모은 데이터
│  │  ├─ towers.js
│  │  ├─ enemies.js
│  │  └─ maps.js
│  ├─ ui/
│  │  ├─ render.js       # 캔버스 그리기, SVG 불러오기
│  │  ├─ input.js        # 마우스와 터치를 하나로 처리
│  │  └─ hud.js          # 정보 바, 패널, 메뉴, 결과창
│  └─ storage.js         # 최고 기록 저장
├─ tests/                # core/와 data/ 테스트 (node --test)
└─ .github/workflows/pages.yml
```

- 맵, 타워, 적의 수치는 `data/`에서만 바꾼다. 밸런스 조정이 쉽다.
- 그림은 `render.js` 한 곳에서만 그린다. 나중에 그림을 바꿔도 코드는 건드리지 않는다.
- 동물 SVG는 이미지로 한 번 불러와 캔버스에 그린다. 적은 처음에는 단순한 도형 몬스터로 그리고, 필요하면 SVG로 바꾼다.
- 파일 경로는 모두 상대 경로로 써서 `/<저장소 이름>/` 하위 주소에서도 동작하게 한다.

## 5. 게임 규칙

아래 수치는 초기값이다. 직접 해 보면서 `data/`에서 조정한다.

**구현 후 조정(2026-10-25):** 자동 플레이 점검에서 한 판이 약 15분이고 다람쥐만으로도 쉽게 클리어되어 다음과 같이 바꿨다.
- 웨이브 사이 대기 15초 → 8초, 스폰 간격은 병사 0.7, 달리기 0.4, 분열체 0.8, 탱크 1.3, 방패병 1.0초, 그룹 사이 간격 1.5초
- 웨이브마다 적 체력 증가율 15% → 20%
- 다람쥐 공격 간격 0.5초 → 0.6초

결과: 한 판 약 10.5분, 타워를 섞어 쓰면 맵별로 생명 5~15개를 남기고 클리어한다(협곡이 가장 어렵다).

### 5.1 기본 규칙

- 시작 생명 20, 시작 골드 150
- 적이 끝까지 가면 생명이 1 줄고(보스는 5), 0이 되면 패배한다.
- 웨이브 15개를 모두 막으면 승리한다.
- 다음 웨이브는 버튼으로 일찍 부를 수 있고, 일찍 부르면 보너스 골드를 준다.
- 적을 잡으면 골드를 얻는다. 타워를 팔면 설치비의 70%를 돌려받는다.

### 5.2 타워 (동물)

> 2026-10-26: 설치비와 골드 업그레이드는 11절의 랜덤 소환과 합성으로 바뀌었다. 아래 표의 설치비는 더 이상 쓰지 않는다.

업그레이드는 3단계이고 단계마다 비용이 오른다. 타워는 길에서 가장 앞선 적을 노린다.

| 동물 | 설치비 | 역할 |
|---|---|---|
| 🐿️ 다람쥐 | 50 | 기본. 사거리 중간, 연사 빠름 |
| 🐘 코끼리 | 90 | 느리지만 범위 피해 |
| 🐧 펭귄 | 70 | 피해는 낮고 적을 감속 |
| 🦅 독수리 | 120 | 사거리 길고 단일 고피해, 보스에 강함 |
| 🐍 뱀 | 80 | 독으로 시간 지속 피해, 체력 많은 적에 강함 |

위 이모지는 설명용이다. 그림은 처음에 SVG로 만들었다가, 2026-10-26에 적과 같은 16×16 도트 그림(`js/data/animals.js`)으로 바꿨다. 레벨은 성장 단계로 보여준다(2026-10-26 변경): 0 아기(몸이 작고 머리가 큰 비율), 1 청년, 2 성체, 3 각성(성체 그림 + 속성 색 오라가 맥동하고 빛 조각이 떠오름). 정보창에는 '다람쥐 · 아기'처럼 단계 이름을 보여준다. 타워는 마지막으로 쏜 적 쪽을 바라본다. 이미지 파일을 불러오지 않으므로 이모지 대체는 없앴다.

### 5.3 적

| 적 | 특징 |
|---|---|
| 병사 | 보통 체력, 보통 속도 |
| 달리기 | 체력 낮고 빠름 (감속이 효과적) |
| 탱크 | 체력 높고 느림 (독, 단일 고피해가 효과적) |
| 방패병 | 일반 공격에 피해 감소, 독은 그대로 받음 |
| 분열체 | 죽으면 작은 적 2마리로 쪼개짐 (범위 피해가 효과적) |
| 보스 | 웨이브 5, 10, 15에 등장, 체력 매우 높음 |

### 5.4 웨이브와 맵

- 웨이브마다 적 수와 체력이 오르고, 새로운 종류가 점점 섞여 나온다.
- 맵 3개는 경로 모양과 설치 칸 수가 다르다. 맵은 16×10칸 격자를 기준으로 한다.
- 맵마다 바닥 테마가 있다(2026-10-26 추가): 1단계 초원(기존 그림), 2단계 숲(픽셀 풀밭, 흙길, 장애물은 나무), 3단계 바다(물결 타일, 길은 판자 다리, 장애물은 암초, 타워 밑에 모래섬). 3단계 이름은 협곡에서 바다로 바꿨고, 저장 기록 호환을 위해 id `canyon`은 유지한다.

### 5.5 기록

맵별로 클리어 여부, 최고 웨이브, 남은 생명 기준 별 1~3개를 저장한다.

## 6. 화면과 조작

### 6.1 화면 배치

- 캔버스는 가로세로 비율을 유지하며 화면에 맞게 줄어든다.
- 세로 화면(폰): 위에 정보 바(생명, 골드, 웨이브), 가운데 맵, 아래에 동물 선택 패널.
- 가로 화면(PC): 패널이 맵 오른쪽에 온다.
- 정보 바에 일시정지와 배속(1x, 2x) 버튼이 있다.

### 6.2 조작

> 2026-10-26: 동물을 골라 칸을 누르는 설치 방식은 11절의 소환 버튼과 드래그 합성으로 바뀌었다.

마우스와 터치를 같은 방식으로 처리한다.

1. 아래 패널에서 동물을 누르면 선택된다. 골드가 모자라면 흐리게 표시되고 선택되지 않는다.
2. 맵의 빈 칸을 누르면 설치된다. 선택 중에는 설치 가능한 칸이 밝게 표시되고, 사거리가 원으로 미리 보인다.
3. 설치된 동물을 누르면 정보창이 뜬다: 사거리, 능력치, 업그레이드(비용 표시), 판매.
4. 빈 곳을 누르면 선택이 해제된다.

PC 보조 단축키: 1~5로 동물 선택, 스페이스로 일시정지, ESC로 선택 해제. 모바일에서는 화면 확대와 스크롤이 게임 조작을 방해하지 않도록 막는다.

### 6.3 메뉴

- 시작 화면에서 맵 3개를 고른다. 잠긴 맵은 자물쇠로 표시하고, 열린 맵에는 최고 기록(별, 최고 웨이브)이 보인다.
- 승리나 패배 시 결과창에서 다시 하기와 맵 선택으로 갈 수 있다.

### 6.4 광고 자리

게임 화면 안에는 광고를 넣지 않는다. 맵 선택 화면과 결과창 아래에만 자리를 비워 둔다. 실제 광고 코드는 이번 범위에 넣지 않는다.

## 7. 저장과 오류 처리

- `localStorage`의 키 하나(`td-save-v1`)에 JSON으로 저장한다: 열린 맵, 맵별 최고 웨이브, 별 개수.
- 저장 데이터가 깨졌거나 읽을 수 없으면(시크릿 모드, 저장 차단) 기본값으로 시작하고 게임은 그대로 돌아간다. 저장이 안 된다는 안내만 작게 보여준다.
- 버전 번호를 넣어 두어, 구조가 바뀌어도 이전 기록을 옮길 수 있게 한다.
- SVG를 불러오지 못하면 해당 동물을 이모지로 대신 그린다.
- 화면 크기가 바뀌거나 탭이 백그라운드로 가면 자동 일시정지하고, 돌아오면 시간 점프 없이 이어간다.

## 8. 테스트

`node --test`로 `core/`와 `data/`만 검사한다. 외부 패키지는 쓰지 않는다.

- 경로 위 위치 계산, 설치 가능 칸 판정
- 타워 목표 선택(가장 앞선 적), 사거리 안팎 판정, 연사 간격
- 피해 계산: 방패병 피해 감소, 독 지속 피해, 감속 효과, 분열체 쪼개짐
- 골드와 생명 변화, 판매 환급 70%, 업그레이드 비용과 한도
- 웨이브 스케줄: 모든 맵과 웨이브가 정의되어 있는지, 보스가 5, 10, 15번에 나오는지
- 데이터 점검: 맵 경로가 끊기지 않았는지, 설치 칸이 경로와 겹치지 않는지, 모든 수치가 양수인지
- 저장 데이터가 깨졌을 때 기본값으로 돌아가는지

화면 렌더링과 터치 조작은 자동 테스트가 어려우므로, 구현 후 Playwright로 브라우저를 열어 직접 눌러 보며 확인한다.

## 9. 배포

- 새 저장소에 올리고, `master` 푸시 시 GitHub Actions가 테스트를 통과한 경우에만 GitHub Pages로 배포한다. 기존 무료 도구 사이트와 같은 방식이다.
- 주소는 `luneeest-lang.github.io/<저장소 이름>/`이다.
- 기존 사이트에는 나중에 링크 한 줄만 추가한다. 이번 범위에는 넣지 않는다.

## 10. 열린 사항

- 새 저장소의 이름과 공개 여부는 아직 정하지 않았다. 구현 시작 전에 정하고, 만들기 전에 확인받는다.
- 이 설계 문서는 새 저장소가 생기면 그쪽으로 옮긴다.

## 11. 랜덤 소환과 합성 (2026-10-26 변경)

골드로 원하는 동물을 사서 놓고 골드로 업그레이드하던 방식을 바꿨다.

- **소환:** [소환] 버튼(PC는 `S`)을 누르면 5종 중 하나가 같은 확률로 나와, 길 바로 옆(대각선 포함 1칸) 빈 칸 중 무작위 위치에 아기 단계로 놓인다. 길에서 먼 칸은 사거리 밖이라 제외했다.
- **비용:** 첫 소환 50골드, 소환할 때마다 +5골드. 골드가 모자라거나 소환할 칸이 없으면 버튼이 꺼진다. 시작 골드는 150에서 200으로 올렸다(초반 3마리).
- **합성:** 타워를 끌어 같은 동물·같은 단계 타워 위에 놓으면, 놓인 자리의 타워가 한 단계 성장하고 끌어온 타워는 사라진다. 아기+아기→청년, 청년+청년→성체, 성체+성체→각성. 각성은 더 합칠 수 없다. 끄는 동안 합칠 수 있는 타워가 빛난다. 빈 칸이나 다른 타워 위에 놓으면 제자리로 돌아간다(이동 없음).
- **각성 모습:** 성체에 왕관을 쓰고 속성 색 오라가 생긴다.
- **판매:** 타워를 탭하면 정보창이 뜨고 판매만 할 수 있다. 환급은 그 타워에 들어간 소환 비용 합계(합성 재료 포함)의 70%(내림).
- **성장 수치:** 한 단계마다 공격력과 독 피해 ×2.2(재료 두 개보다 강하게), 공격 간격 ×0.9, 사거리 +0.25, 감속 배율 ×0.85(하한 0.3).
- **밸런스 점검:** 돈이 되면 소환하고 짝이 생기면 바로 합치는 단순 자동 플레이로, 맵마다 시드 20개 기준 승률 70~90%, 한 판 약 9~10분.

## 12. 웨이브 구성, 쉬는 시간, 세로 화면 (2026-10-26 변경)

- **웨이브마다 20마리:** 모든 웨이브는 보스를 포함해 정확히 20마리다(분열체가 죽으며 생기는 작은 슬라임은 제외). 구성은 `js/core/waves.js`의 표로 정한다. 새 적이 처음 나오는 웨이브(달리기 3, 분열체 4, 탱크 6, 방패병 8, 보스 5·10·15)는 그대로다.

## 13. 보스 웨이브 (2026-10-26 변경)

## 14. 효과와 연출 (2026-10-26 추가)

효과 상태(종류, 수명, 개수 상한 400개, 흔들림·번쩍임 세기)는 `js/ui/effects.js`에 화면과 분리해 두고 테스트한다. 그리기는 `render.js`가 한다. 규칙 쪽 이벤트에는 맞은 적(`targetId`), 처치한 적 종류와 보상, 집 도착(`leak`)을 담는다.

- **공격:** 동물마다 다른 발사체가 0.18초 동안 날아간다. 다람쥐는 도토리, 코끼리는 돌덩이와 충격파 고리, 펭귄은 얼음 조각, 독수리는 금빛 궤적, 뱀은 독 방울이다.
- **피격:** 맞은 몬스터가 0.09초 동안 하얗게 번쩍인다(미리 구운 흰 실루엣).
- **처치:** 몬스터 색의 픽셀 파편이 튀어 화면 아래로 떨어지고, 금색 보상 숫자(+5 등)가 떠오른다. 보스는 파편이 더 많고 붉은 고리와 화면 흔들림이 있다.
- **집 도착:** 화면 가장자리가 붉게 번쩍이고 상단 생명 숫자가 흔들린다. 골드가 늘면 골드 숫자가 살짝 커진다.
- **소환:** 하얀 고리와 반짝임이 생긴다.
- **합성:** 금빛 고리와 파편, "성장!" 문구가 나온다. 각성 때는 더 큰 폭발, "각성!" 문구, 약한 화면 흔들림이 있다.
- 세로 화면에서도 글자와 파편은 화면 기준으로 그린다. 동작 줄이기 설정에서는 화면 흔들림과 숫자 애니메이션을 끈다.

## 17. 맵 이름, 체력바, 데미지 숫자 (2026-10-26)

- **맵 이름:** 초급(돌산), 중급(숲), 고급(바다). id는 그대로다.
- **체력바:** 몬스터 머리 위에 두꺼운 빨간 바(칸의 약 16% 두께, 최소 5px)를 어두운 테두리·배경과 함께 그린다.
- **데미지 숫자:** 규칙 쪽이 맞은 적마다 실제로 들어간 피해량을 `hit` 이벤트(`enemyId`, `amount`, 위치)로 내보내고, 화면은 노란 숫자(반올림, 최소 1)를 0.65초 동안 띄운다. 방패병은 절반, 보스는 독수리 1.5배처럼 실제 값이 나온다. 독 지속 피해는 숫자가 너무 많아져서 띄우지 않는다. 보상 숫자(+골드)는 주황빛 금색으로 구분한다.

## 18. 메뉴 배경 이름, 몬스터 간격 (2026-10-26)

- **메뉴:** 맵 데이터에 `place`(배경 이름)를 두고 메뉴에 "초급 · 돌산", "중급 · 숲", "고급 · 바다"로 보여준다.
- **체력바 겹침 해소:** 같은 무리의 몬스터는 최소 약 1칸(스폰 간격 x 속도 ≥ 0.95칸) 떨어져 나온다. 간격은 병사 0.95, 달리기 0.5, 분열체 0.95, 방패병 1.1, 탱크 1.6초다. 빠른 무리가 먼저 나오도록 달리기 → 병사 → 분열체 → 방패병 → 탱크 → 보스 순서로 스폰해 뒤 무리가 앞 무리를 따라잡지 않는다. 체력바는 몬스터 그림을 모두 그린 뒤 그려 다른 그림에 가려지지 않는다. 감속에 걸린 적은 뒤 적에게 따라잡혀 잠깐 겹칠 수 있다.

## 19. 맵별 난이도, 상단 바 고정 (2026-10-27)

- **맵별 난이도:** 세 맵의 수치가 같아 난이도 차이가 없었다. 맵마다 몬스터 체력 배율(`hpMult`)을 둔다. 초급 ×1.0, 중급 ×1.7, 고급 ×2.2이고, 분열체가 남기는 작은 슬라임에도 적용한다. 자동 플레이 기준(맵마다 20판) 승률은 초급 100%, 중급 95%, 고급 50%이고, 이길 때 남은 생명은 각각 약 19.6, 14.4, 12.3개다.
- **상단 바 고정:** 다음 웨이브 버튼 글자 길이가 바뀔 때마다 휴대폰에서 줄바꿈이 달라져 버튼과 맵이 움직였다. 상단 바를 칸이 고정된 격자로 바꿨다. 휴대폰은 윗줄 생명·골드·웨이브, 아랫줄 웨이브 버튼·배속·일시정지·메뉴이고, 넓은 화면은 한 줄에 웨이브 버튼 폭을 고정한다. 숫자는 고정폭 숫자를 쓰고, 버튼 문구는 "⏭ 바로 시작 10초 +10🪙"로 줄여 360px 폭에서도 잘리지 않는다.

## 20. 동물별 강화, 합성 결과 랜덤 (2026-10-27)

- **동물별 강화:** 패널의 동물 5칸이 강화 버튼이다. 누르면 그 동물 전체(놓인 것과 앞으로 소환될 것)가 한 레벨 강해진다. 레벨마다 공격력·독 피해 +20%, 펭귄 감속 시간 +10%이고, 사거리와 공격 속도는 그대로다. 최대 Lv.5, 비용은 80·120·160·200·240골드(`CONFIG.upgradeCosts`)이고 한 판 안에서만 유지된다. 버튼에 현재 레벨과 다음 비용이 나오고, 골드가 모자라거나 최대면 꺼진다.
- **합성 결과 랜덤:** 합치는 조건(같은 동물·같은 단계)은 그대로이고, 결과는 5종 중 같은 확률로 고른 동물의 다음 단계다. 합성 연출에 "성장! 펭귄"처럼 결과 동물 이름을 보여준다.
- **난이도 재조정:** 결과가 무작위라 다음 합성 짝이 잘 맞지 않아 높은 단계 동물이 크게 줄었다(자동 플레이에서 각성이 이전의 약 1/4). 그래서 중급과 고급의 체력 배율을 1.7→1.2, 2.2→1.55로 낮췄다. 두 가지 자동 전략(항상 합성, 꽉 차면 합성) 평균 승률은 초급 약 95~100%, 중급 약 88%, 고급 약 53%다.
- 단순 자동 플레이는 골드를 대부분 소환에 써서 강화를 거의 하지 않는다. 강화는 같은 동물이 많이 모이는 후반에 가치가 커지도록 둔다.

## 21. 30웨이브, 카드 선택, 보스 6종과 능력 (2026-10-27)

- **30웨이브:** 웨이브는 30개다. 5·10·15·20·25·30웨이브는 보스 한 마리만 나오고, 순서대로 붉은 악마, 슬라임 왕, 리치 왕, 용암 거인, 그림자 늑대, 흑룡이다. 흑룡은 최종 보스라 2배 크기로 그린다. 나머지 웨이브는 20마리이고, 뒤로 갈수록 병사가 줄고 탱크·방패병이 늘어난다. 소환 비용은 5웨이브마다 5골드씩 계속 오른다.
- **몬스터 강화:** 웨이브마다 이동 속도 +1%, 방패병이 직접 공격에서 받는 피해가 50%에서 35%까지 줄어든다. 체력은 웨이브마다 기본의 30%씩 늘고, 10웨이브 뒤로는 웨이브마다 1.1배씩 더 늘어난다(카드가 쌓이는 후반 대응). 11웨이브부터 일반 몬스터 발밑에 주황, 21웨이브부터 보라 기운이 보인다.
- **카드 선택:** 마지막을 뺀 웨이브를 막을 때마다 13장 중 무작위 3장이 나오고, 하나를 고를 때까지 게임이 멈춘다(숫자키 1~3도 된다). 동물별 공격력 +30%(5종), 공격 속도 +10%, 사거리 +0.3, 골드 +100, 생명 +3, 무료 소환 2번, 처치 보상 +1, 적 속도 −8%, 보스 피해 +25%다. 고른 카드는 패널 아래에 아이콘과 개수로 보인다.
- **보스 능력 (중급·고급만):** 붉은 악마는 체력 절반 이하에서 1.5배 빨라진다. 슬라임 왕은 체력 75·50·25%에서 작은 슬라임 2마리씩 낳는다. 리치 왕은 5초마다 방패병을 불러낸다(최대 6). 용암 거인은 받는 피해가 30% 적다. 그림자 늑대는 6초마다 1.5초 동안 3배로 질주한다. 흑룡은 8초마다 포효해 2.5칸 안의 타워를 2초 동안 기절시킨다. 능력이 발동하면 "분노!", "질주!" 같은 문구와 고리가 뜨고, 기절한 타워는 흐려지고 머리 위에 별이 돈다. BOSS 경고 아래에 "리치 왕이 다가온다…"처럼 보스 이름이, 중급부터는 능력 설명이 함께 나온다.
- **난이도:** 시작 골드를 200→250으로 올려 첫 웨이브에 나쁜 합성이 겹쳐 지는 일을 줄였다. 체력 배율은 중급 1.18, 고급 1.5다. 카드를 무작위로 고르는 자동 플레이(맵마다 40판) 승률은 초급 98%, 중급 80%, 고급 53%이고, 한 판은 약 24분이다. 고급에서 지는 판은 대부분 26~30웨이브다.

## 22. 휴대폰 화면 맞춤, 단차 블록 맵 (2026-10-27)

- **화면 맞춤:** 휴대폰을 가로로 들면 오른쪽 패널이 세로 한 줄 + 줄바꿈 배치라 강화 버튼이 화면 오른쪽 밖으로 밀려 잘렸다. 패널은 줄바꿈 없이 세로로만 쌓고 넘치면 스크롤한다. 게임 화면은 화면 높이에 딱 맞춘 격자(상단 바 / 맵 자리 / 패널)이고, 맵 크기는 브라우저별 CSS 단위(`dvh`, `aspect-ratio`) 지원에 기대지 않고 `fitBoard`(js/ui/layout.js)가 맵 자리를 재서 16:10(세로로 길면 돌려서 10:16)로 최대한 크게 맞춘다. 가로 배치는 폭 560px부터 쓰고, 높이 500px 이하(가로로 든 휴대폰)는 상단 바와 패널을 촘촘하게 한다. 360~915px 휴대폰 9가지 크기에서 스크롤·잘림이 없는 것을 확인했다.
- **단차 블록 맵:** 돌산과 숲은 땅이 한 단 높고 길이 파여 있고, 바다는 판자 다리가 물 위로 솟아 있다. 높고 낮음은 화면 기준으로 계산(`reliefCells`, js/ui/relief.js)해서 세로 화면에서 맵을 돌려도 벽은 항상 화면 아래를, 빛은 왼쪽 위를 향한다. 낮은 칸 위쪽에 높은 칸의 앞면 벽(돌산: 바위 지층, 숲: 흙벽과 늘어진 풀, 바다: 다리 옆면과 기둥)과 그 아래 그림자를, 왼쪽이 높으면 그림자를, 높은 칸 모서리에는 빛과 어두운 테두리를 그린다. 바위·나무·암초와 타워 발밑에 그림자를 깔고, 맵 전체에 왼쪽 위가 밝은 조명을 얹는다.
- **여백 채우기:** 맵 비율(16:10)과 화면 비율이 달라 휴대폰에서 양옆(또는 위아래)이 비어 보였다. 캔버스를 맵 자리 전체로 키우고 맵은 가운데에 둔다. 바깥 여백은 같은 테마의 바닥 타일(돌산 땅, 숲 풀, 바다 물결)로 채우고 바위·나무·암초를 드문드문 놓되, 놀 수 없는 곳임을 알 수 있게 살짝 어둡게 하고 맵 경계에 얇은 그림자를 그린다. 터치는 `boardRect()`로 맵 자리를 받아 칸을 계산하고 여백을 누르면 아무 칸도 고르지 않는다.

## 23. 등급과 신화 조합 (2026-10-27)

- **등급:** 성장 단계에 등급을 붙인다. 아기·청년은 일반, 성체는 희귀(발밑 파란 고리), 각성은 전설(보라 고리와 기존 오라), 조합으로 만든 동물은 신화(무지개 고리)다. 정보창에 "다람쥐 · 성체 (희귀)"처럼 나온다. 합성 규칙은 그대로다.
- **신화 5종:** 기본 동물과 전혀 다른 20x20 도트 그림이고, 무지개 고리·은은한 빛·도는 반짝이와 함께 살짝 떠 있다. 재료는 정해진 각성 2마리와 성체 1마리(셋 다 다른 동물)이고, 첫째 재료 자리에 신화가 생긴다. 투자액은 합산하고, 신화는 합칠 수 없지만 판매는 된다.
  - 불사조(각성 독수리 + 각성 다람쥐 + 성체 펭귄): 불꽃 깃털을 쏘고 맞은 자리에 3초 동안 불길이 남아 지나가는 적을 태운다.
  - 구미호(각성 뱀 + 각성 독수리 + 성체 코끼리): 여우불 4개가 앞선 적 4마리를 동시에 맞히고, 맞은 적을 12% 확률로 홀려 1칸 뒤로 밀어낸다(보스는 홀리지 않는다).
  - 천마(각성 펭귄 + 각성 뱀 + 성체 코끼리): 첫 적 쪽으로 사거리 끝까지 뻗는 바람 줄기가 줄 안의 적을 모두 꿰뚫고, 2칸 안의 일반 동물은 공격 속도가 1.25배가 된다.
  - 해태(각성 코끼리 + 각성 뱀 + 성체 다람쥐): 3초마다 땅을 울려 맵 전체의 적에게 피해를 주고 1.5초 느리게 한다.
  - 기린(각성 다람쥐 + 각성 독수리 + 성체 뱀): 아주 빠르게 공격하고 보스에게 2배 피해, 기린이 잡은 적은 골드 +2.
- **성장:** 신화는 첫째 재료 동물의 강화 레벨과 그 동물의 훈련 카드를 이어받고, 공격 속도·사거리·보스 피해 카드도 받는다. 흑룡의 포효에는 신화도 기절한다.
- **화면:** 패널의 "✨ 신화" 버튼(만들 수 있으면 무지개로 반짝인다, 단축키 M)으로 조합표를 연다. 조합표는 신화마다 재료 칸(있으면 ✔)과 만들기 버튼을 보여 주고, 열려 있는 동안 게임이 멈춘다. 만들면 "신화 탄생!" 문구와 무지개 파편, 화면 흔들림이 나온다.
- **재료를 각성 2마리로 정한 이유:** 처음 설계(각성 1 + 성체 2)는 자동 플레이가 한 판에 평균 4마리, 첫 신화를 5~10웨이브에 만들어 장기 목표가 되지 못했고 고급 승률이 88%까지 올랐다. 각성 2마리로 올리자 한 판에 2~3마리, 첫 신화가 평균 12웨이브쯤으로 늦춰졌다.
- **신화의 힘과 난이도:** 신화는 재료(각성 2 + 성체 1)보다 확실히 강해야 만들 이유가 생긴다. 공격력은 불사조 450(불길 225/초), 구미호 225 x 4, 천마 375, 해태 375(맵 전체), 기린 135(0.2초마다)다. 그만큼 맵 체력 배율을 중급 1.3, 고급 2.05로 올렸고, 어려운 맵에서 운이 나쁘면 2~3웨이브에 바로 지던 문제를 막으려고 배율은 1~8웨이브 동안 서서히 올라간다(`mapHpMult`). 신화를 만들 수 있으면 만드는 자동 플레이(맵마다 40판) 승률은 초급 100%, 중급 약 88%, 고급 약 52%이고, 신화를 만들지 않으면 중급·고급이 크게 어려워진다(같은 수치에서 약 60%, 23%). 신화는 한 판에 평균 2~3마리, 첫 신화는 평균 12웨이브쯤 나온다.
- **그림 다듬기 (2026-10-27):** 신화 그림을 뾰족한 실루엣과 강한 명암으로 날카롭게 다시 그렸다. 불사조는 테두리 없는 불꽃 날개·꼬리에 불빛이 일렁이고 불티가 피어오른다. 해태는 붉은 눈의 백호(🐯), 기린은 긴 목·긴 다리의 실제 기린 모양에 초록 몸과 금빛 뿔(🦒), 천마는 붉은 눈과 보라 갈기의 검은 말이다.

## 24. 이어하기, 효과음과 배경음 (2026-10-27)

- **이어하기:** 한 판이 약 24분이라 휴대폰에서 중간에 끊기기 쉽다. 웨이브와 웨이브 사이(적도 스폰 예정도 없고, 카운트다운 중이거나 카드를 고르는 중)의 상태를 `td-run-v1`에 자동 저장한다(`core/snapshot.js`). 저장 시점은 웨이브 클리어 직후, 카드 선택·소환·합성·강화·판매·신화 조합 직후, 메뉴로 나갈 때, 앱을 내릴 때다. 저장하는 것은 맵, 골드, 생명, 웨이브, 동물(종류·단계·자리·투자액·신화), 동물별 강화, 카드 효과와 고른 카드, 고르던 카드 3장이다. 움직이는 몬스터는 저장하지 않으므로 웨이브 도중에 나가면 그 웨이브가 시작되기 직전으로 돌아간다. 되살리면 다음 웨이브 카운트다운을 처음부터 다시 센다. 메뉴 맨 위에 "▶ 이어하기 (초급 · 돌산 · 웨이브 7/30)" 버튼이 나오고, 이어할 게임이 있는데 새 게임을 시작하면 지워진다고 한 번 묻는다. 게임이 끝나면(승리·패배) 저장을 지우고, 아무것도 하지 않은 새 게임은 저장하지 않는다. 저장 내용이 하나라도 이상하면(맵, 숫자, 동물 자리 겹침, 없는 카드 등) 되살리지 않고 버린다.
- **효과음과 배경음:** 소리 파일 없이 Web Audio로 도트 게임풍 소리를 만든다(`ui/sound.js`). 효과음은 소환, 합성, 각성, 신화 탄생, 강화, 카드 선택, 판매, 몬스터 처치(짧은 퐁), 보스 처치(폭발과 팡파르), 생명 잃음, 웨이브 클리어, 보스 능력, 흑룡 포효, 해태 지진, 구미호 홀림, 보스 경고(낮은 울림), 승리, 패배다. 발사와 피해 숫자는 너무 잦아 소리를 내지 않고, 같은 소리는 최소 간격을 두어 겹치지 않게 한다. 배경음은 도·레·미·솔·라 음계의 잔잔한 반복으로, 게임 중이고 일시정지가 아닐 때만 나온다. 상단 바의 소리 버튼은 🔊(전체) → 🔉(효과음만) → 🔇(끄기) 순서로 바뀌고 `td-sound-v1`에 기억한다. 브라우저는 화면을 누르기 전에는 소리를 막으므로 처음 누르거나 키를 칠 때 소리를 켠다.
- **소리 다듬기:** 카드 3장이 뜰 때(웨이브 클리어)와 카드를 고를 때는 효과음을 내지 않는다(배경음은 그대로). 보스 경고음은 약 3초 동안 배음이 어긋난 낮은 종소리, 서로 어긋나 맥놀이하는 세 온음 불협화음(점점 커지고 밝아짐), 쿵-쿵 심장 박동 세 번, 스산한 바람을 겹친다. 배경음은 라단조로 바꿔 8분음표로 달리는 베이스(라·라·라·라·파·파·솔·솔, 뒤 두 마디는 솔#으로 긴장), 큰북·작은북·하이햇, 띄엄띄엄 나오는 선율로 긴장감을 준다. 소리 버튼은 🎵 배경음과 🔊 효과음 두 개로 나눠 따로 켜고 끄며(꺼지면 흐려지고 빨간 사선), `td-sound-v2`에 저장한다. 예전 설정(`td-sound-v1`)은 옮겨 읽는다.

## 25. 카드는 보스를 잡은 뒤에만 (2026-10-27)

- **언제:** 카드 3장 중 1장 고르기는 보스 웨이브(5·10·15·20·25)를 깬 뒤에만 나온다. 30웨이브는 마지막이라 없으므로 한 판에 5번이다(예전에는 매 웨이브, 29번).
- **보스 보상답게 강하게:** 카드가 29번에서 5번으로 줄자 자동 플레이 승률이 초급 42%, 중급 0%, 고급 2%로 떨어졌다. 몬스터를 크게 약하게 하는 대신 한 장 한 장을 키웠다(`CARD_POWER`, 설명 문구도 이 값에서 만든다). 동물 특훈 +100%, 공격 속도 +40%, 사거리 +1칸, 골드 +400, 생명 +10, 무료 아기 소환 6마리, 처치 보상 +4, 몬스터 이동 속도 −25%, 보스 피해 +100%.
- **난이도 재조정:** 카드가 쌓이기 전인 10~16웨이브에 많이 져서 맵 체력 배율을 중급 1.1, 고급 1.55로, 10웨이브 뒤 웨이브마다 추가로 늘어나는 체력을 1.1배에서 1.07배로 낮췄다. 자동 플레이(맵마다 40판) 승률은 초급 100%, 중급 85%, 고급 50%이고 한 판은 약 23분이다.

## 26. 여백과 맵의 일체감, 풍성한 맵 (2026-10-28)

- **여백:** 맵 바깥 여백을 어둡게 칠하고 테두리를 긋던 것을 없애, 맵과 같은 땅이 이어지게 했다. 맵을 돌려 그릴 때 가장자리에 생기던 1픽셀 미만의 틈이 보이지 않도록 바닥 타일을 맵 가장자리 안쪽까지 깐다.
- **장식:** 테마마다 16x16 장식 그림(`data/decor.js`)을 흩뿌린다. 돌산은 조약돌·마른 풀·하얀 들꽃(바닥), 작은 바위·소나무·푸른 수정(키 큼). 숲은 빨강·노랑 꽃무리·버섯·고사리(바닥), 덤불·쓰러진 통나무·그루터기(키 큼). 바다는 해초·산호(바닥), 물보라 바위·떠다니는 나무통(키 큼). 자리는 칸 좌표의 해시로 정해 늘 같고(`ui/decor.js`), 칸 안에서 조금씩 어긋나게 놓는다. 바닥 장식은 길이 아닌 칸 약 28%에, 키 큰 장식은 길에서 2칸 이상 떨어진 칸(동물이 소환되지 않는 칸) 약 25%에 놓아 게임을 가리지 않는다. 여백에는 큰 나무·바위·암초도 섞는다.
- **움직이는 것들:** 모든 맵에 천천히 지나가는 구름 그림자, 숲에는 나비 4마리, 돌산에는 새, 바다에는 갈매기와 물고기 그림자(다리 아래로 지나가면 가려진다), 물결 반짝임. 동작 줄이기 설정이면 그리지 않는다. 휴대폰 세로 화면에서 초당 약 53프레임을 유지한다.

## 27. 2배 해상도와 가독성 (2026-10-28)

- **2배 해상도:** 모든 그림(동물 20단계, 신화 5종, 몬스터, 바닥 타일, 장식)을 구울 때 32x32(신화 40x40)로 다듬는다(`ui/refine.js`). 원본 16x16 문자 그림은 그대로 두어 손으로 고치기 쉽다. 다듬기는 (1) scale2x로 계단 모양 사선·곡선을 매끄럽게, (2) 두꺼워진 바깥 테두리의 안쪽 줄을 몸 색과 섞어 테두리를 1픽셀로, (3) 왼쪽 위 가장자리는 밝게·오른쪽 아래는 어둡게 1픽셀 명암, (4) 바닥 타일은 고운 결(가장자리는 같은 색으로 이어 모서리에 빈 픽셀이 생기지 않게)이다. 길 옆 절벽의 무늬와 가장자리 선도 같은 해상도로 가늘게 그린다.
- **가독성:** 동물·신화는 밝은 1픽셀 바깥 테두리, 몬스터는 옅은 바깥 테두리를 둘러 배경에서 돋보이게 하고, 장식은 색을 25% 차분하게 해 뒤로 물러나게 한다.
- **크기:** 32픽셀 그림을 정수 배로만 키우면 크기 오차가 커서(동물이 약 20% 작아짐) 화면 픽셀 기준 0.5배 단위로 맞춘다. 한 번 구운 그림은 다시 쓴다(컴퓨터에서 전체 굽기 약 0.16초).

## 28. 블랙홀과 빨려 드는 연출, 타워 크기 (2026-10-28)

- **타워 크기:** 동물·신화(끌고 있는 동물, 바다의 모래섬 포함)를 10% 키웠다(`TOWER_SCALE`).
- **블랙홀:** 길 끝의 집(🏠) 대신 빨간 블랙홀을 그린다. 붉은 빛무리, 바깥은 밝은 빨강·안쪽은 검붉은 소용돌이 원반, 안으로 말려 드는 나선 팔 셋(계속 돈다), 바깥에서 나타나 돌며 핵으로 떨어지는 불티, 검은 핵과 붉은 테두리다. 숨 쉬듯 조금씩 커졌다 작아진다.
- **빨려 드는 연출:** 몬스터가 도착하면(`leak`) 그 몬스터 그림이 블랙홀 주위를 한 바퀴 반 돌며 비틀리고 작아지다 사라진다(0.65초). 그동안 블랙홀이 크게 꿀렁이며 밝아지고(`portalPulse`), 화면 가장자리가 붉게 번쩍인다. 생명을 잃는 소리는 아래로 미끄러지는 "슈욱" 소리와 휘몰아치는 바람으로 바꿨다.
- **백호 다시 그리기 (2026-10-28):** 20x20을 자동으로 키운 백호는 흰 털 위에 이목구비가 뭉개져 무슨 동물인지 알기 어려웠다. 백호만 40x40으로 직접 그렸다(`MYTHIC_NATIVE`, 자동 다듬기 없이 밝은 바깥 테두리만 두른다). 처음엔 정면 얼굴로 그렸다가 요청에 따라 옆모습으로, 다시 몸통과 얼굴 비율을 실제 호랑이처럼(긴 몸통, 몸 길이의 절반쯤 되는 머리, 네 다리로 선 자세, 굵은 다리와 넓은 발) 바꿨다: 크고 둥근 머리, 짧고 뭉툭한 주둥이 끝의 분홍 코, 겹쳐 보이는 귀 두 개(앞 귀 안쪽 분홍), 뒤로 뾰족하게 뻗친 볼털, 이마의 가는 줄무늬 세 개와 볼·귀 뒤·턱 줄무늬, 눈 아래로 흐르는 검은 눈물 줄무늬, 비스듬한 검은 눈썹과 붉은 눈, 입선과 송곳니, 2픽셀 쐐기 줄무늬의 몸과 고리 무늬 꼬리, 푸른 회색 그림자다.

## 29. 황금 몬스터와 판 중 미션 (2026-10-28)

- **판마다 무작위 타이밍:** 새 게임마다 황금 몬스터 4번(3~25웨이브 중 보스 웨이브를 뺀 웨이브)과 미션 5번(2~24웨이브에 시작)을 무작위로 정한다(`core/missions.js`의 `rollSchedule`). 미션이 진행 중이면 다음 미션은 다음 웨이브로 미뤄지고, 25웨이브가 넘으면 새 미션은 시작하지 않는다. 남은 일정·진행 중인 미션·진행 횟수는 이어하기에 함께 저장한다(예전 저장은 새 일정으로 이어한다).
- **황금 몬스터:** 정해진 웨이브 도중 무작위 시점에 한 마리 나온다. 달리기 몬스터를 금빛으로 칠한 모습에 금빛 후광과 금가루, 등장 알림 "✨ 황금 몬스터 출현!"과 반짝이는 소리. 체력 100(웨이브·맵 배율 적용), 속도 2.6으로 아주 빠르다. 잡으면 골드 50 + 웨이브×5(금화 폭죽, 동전 쏟아지는 소리), 블랙홀에 닿으면 생명을 깎지 않고 "도망갔다…".
- **미션 8종:** 맵 위쪽 띠에 "🎯 목표 (진행/목표) · 보상 · 남은 웨이브"를 보여준다. 기한 안에 깨면 보상과 "🎯 미션 성공!", 못 깨면 "미션 실패…".
  - 몬스터 처치(2웨이브): 기한 동안 나올 몬스터의 85% → 골드 60+6×웨이브
  - 생명을 잃지 않고 웨이브 클리어(2웨이브) → 생명 +2
  - 각성 동물 만들기(4웨이브) → 무료 소환 2번
  - 같은 동물 3마리 모으기(3웨이브) → 그 동물 강화 1단계 무료(최대면 골드 80)
  - 황금 몬스터 잡기(5웨이브, 기한 안에 황금 몬스터가 남아 있을 때만) → 골드 100+10×웨이브
  - 웨이브 바로 시작 3번(4웨이브) → 골드 40+4×웨이브
  - 동물 강화 2번(4웨이브) → 골드 50+5×웨이브
  - 신화 만들기(6웨이브, 8웨이브부터) → 골드 150+10×웨이브, 생명 +3
  - 처음엔 "몬스터 30마리 처치(3웨이브)"였는데 웨이브마다 20마리라 가만히 있어도 깨져서 위처럼 바꿨다. 같은 미션은 연달아 나오지 않는다.
- **난이도:** 늘어난 골드만큼 맵 체력 배율을 중급 1.4, 고급 2.0으로 올렸다. 자동 플레이(맵마다 40판, 일정 고정) 승률은 초급 100%, 중급 85%, 고급 50%다.
- **소리의 난수:** 효과음의 잡음이 게임의 무작위(소환·합성)를 가져가지 않도록 소리도 화면 연출처럼 전용 난수를 쓴다(브라우저 검사가 가끔 실패하던 원인).
