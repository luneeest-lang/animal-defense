# 동물 타워 디펜스 게임 설계

- 작성일: 2026-10-25
- 상태: 검토 대기
- 저장소: 별도 저장소(가칭 `tower-defense`)에 구현한다. 이 문서는 이동 전까지 이 저장소에 둔다.

## 1. 목표

방문자가 브라우저에서 바로 즐기는 가벼운 2D 경로형 타워 디펜스 게임을 만든다. 광고 수익에 도움이 되도록 로딩이 가볍고, 모바일 터치와 PC 마우스를 모두 지원한다. 서버와 로그인 없이 정적 파일로 배포한다.

## 2. 범위

**포함**
- 맵 3개 (처음에는 1개만 열림, 클리어하면 다음 맵 열림)
- 동물 타워 5종, 타워별 업그레이드 3단계
- 적 5종과 보스
- 15개 웨이브, 한 판 약 8~12분
- 최고 기록 저장 (맵별 최고 웨이브, 별 1~3개, 열린 맵)
- PC와 모바일 조작, 일시정지, 배속(1x, 2x)

**제외 (첫 버전)**
- 사운드
- 계정, 랭킹 서버
- 타워 목표 선택 옵션
- 영구 강화, 스테이지 트리

## 3. 접근 방식

순수 JavaScript와 Canvas를 쓴다. 빌드 도구, 프레임워크, npm 패키지가 없고, 브라우저가 ES 모듈을 직접 불러온다. 로딩이 가볍고 의존성 관리가 필요 없기 때문이다. 게임 엔진(Phaser)과 TypeScript + Vite는 이 규모에 과해서 쓰지 않는다. 게임 규칙을 화면과 분리해 두므로 나중에 엔진으로 옮기기도 어렵지 않다.

## 4. 구조

게임 규칙(`core/`)은 화면을 모르고, 화면(`ui/`)은 규칙의 상태를 읽어서 그리기만 한다. 그래서 규칙은 Node로 테스트할 수 있다.

```
tower-defense/
├─ index.html
├─ css/style.css
├─ assets/animals/       # 동물 5종 SVG (기본 + 업그레이드 1~3단계)
├─ js/
│  ├─ main.js            # 시작점, 게임 루프(requestAnimationFrame)
│  ├─ core/              # 화면 없는 순수 로직
│  │  ├─ game.js         # 한 판의 상태: 골드, 생명, 웨이브 진행
│  │  ├─ path.js         # 경로 위 위치 계산, 설치 가능 칸 판정
│  │  ├─ towers.js       # 목표 선택, 발사, 업그레이드, 판매
│  │  ├─ enemies.js      # 이동, 피해, 상태 이상
│  │  └─ waves.js        # 웨이브 스케줄
│  ├─ data/              # 숫자와 정의만 모은 데이터
│  │  ├─ towers.js
│  │  ├─ enemies.js
│  │  └─ maps.js
│  ├─ ui/
│  │  ├─ render.js       # 캔버스 그리기, SVG 불러오기
│  │  ├─ input.js        # 마우스와 터치를 하나로 처리
│  │  └─ hud.js          # 정보 바, 패널, 메뉴, 결과창
│  └─ storage.js         # 최고 기록 저장
├─ tests/                # core/와 data/ 테스트 (node --test)
└─ .github/workflows/pages.yml
```

- 맵, 타워, 적의 수치는 `data/`에서만 바꾼다. 밸런스 조정이 쉽다.
- 그림은 `render.js` 한 곳에서만 그린다. 나중에 그림을 바꿔도 코드는 건드리지 않는다.
- 동물 SVG는 이미지로 한 번 불러와 캔버스에 그린다. 적은 처음에는 단순한 도형 몬스터로 그리고, 필요하면 SVG로 바꾼다.
- 파일 경로는 모두 상대 경로로 써서 `/<저장소 이름>/` 하위 주소에서도 동작하게 한다.

## 5. 게임 규칙

아래 수치는 초기값이다. 직접 해 보면서 `data/`에서 조정한다.

**구현 후 조정(2026-10-25):** 자동 플레이 점검에서 한 판이 약 15분이고 다람쥐만으로도 쉽게 클리어되어 다음과 같이 바꿨다.
- 웨이브 사이 대기 15초 → 8초, 스폰 간격은 병사 0.7, 달리기 0.4, 분열체 0.8, 탱크 1.3, 방패병 1.0초, 그룹 사이 간격 1.5초
- 웨이브마다 적 체력 증가율 15% → 20%
- 다람쥐 공격 간격 0.5초 → 0.6초

결과: 한 판 약 10.5분, 타워를 섞어 쓰면 맵별로 생명 5~15개를 남기고 클리어한다(협곡이 가장 어렵다).

### 5.1 기본 규칙

- 시작 생명 20, 시작 골드 150
- 적이 끝까지 가면 생명이 1 줄고(보스는 5), 0이 되면 패배한다.
- 웨이브 15개를 모두 막으면 승리한다.
- 다음 웨이브는 버튼으로 일찍 부를 수 있고, 일찍 부르면 보너스 골드를 준다.
- 적을 잡으면 골드를 얻는다. 타워를 팔면 설치비의 70%를 돌려받는다.

### 5.2 타워 (동물)

> 2026-10-26: 설치비와 골드 업그레이드는 11절의 랜덤 소환과 합성으로 바뀌었다. 아래 표의 설치비는 더 이상 쓰지 않는다.

업그레이드는 3단계이고 단계마다 비용이 오른다. 타워는 길에서 가장 앞선 적을 노린다.

| 동물 | 설치비 | 역할 |
|---|---|---|
| 🐿️ 다람쥐 | 50 | 기본. 사거리 중간, 연사 빠름 |
| 🐘 코끼리 | 90 | 느리지만 범위 피해 |
| 🐧 펭귄 | 70 | 피해는 낮고 적을 감속 |
| 🦅 독수리 | 120 | 사거리 길고 단일 고피해, 보스에 강함 |
| 🐍 뱀 | 80 | 독으로 시간 지속 피해, 체력 많은 적에 강함 |

위 이모지는 설명용이다. 그림은 처음에 SVG로 만들었다가, 2026-10-26에 적과 같은 16×16 도트 그림(`js/data/animals.js`)으로 바꿨다. 레벨은 성장 단계로 보여준다(2026-10-26 변경): 0 아기(몸이 작고 머리가 큰 비율), 1 청년, 2 성체, 3 각성(성체 그림 + 속성 색 오라가 맥동하고 빛 조각이 떠오름). 정보창에는 '다람쥐 · 아기'처럼 단계 이름을 보여준다. 타워는 마지막으로 쏜 적 쪽을 바라본다. 이미지 파일을 불러오지 않으므로 이모지 대체는 없앴다.

### 5.3 적

| 적 | 특징 |
|---|---|
| 병사 | 보통 체력, 보통 속도 |
| 달리기 | 체력 낮고 빠름 (감속이 효과적) |
| 탱크 | 체력 높고 느림 (독, 단일 고피해가 효과적) |
| 방패병 | 일반 공격에 피해 감소, 독은 그대로 받음 |
| 분열체 | 죽으면 작은 적 2마리로 쪼개짐 (범위 피해가 효과적) |
| 보스 | 웨이브 5, 10, 15에 등장, 체력 매우 높음 |

### 5.4 웨이브와 맵

- 웨이브마다 적 수와 체력이 오르고, 새로운 종류가 점점 섞여 나온다.
- 맵 3개는 경로 모양과 설치 칸 수가 다르다. 맵은 16×10칸 격자를 기준으로 한다.
- 맵마다 바닥 테마가 있다(2026-10-26 추가): 1단계 초원(기존 그림), 2단계 숲(픽셀 풀밭, 흙길, 장애물은 나무), 3단계 바다(물결 타일, 길은 판자 다리, 장애물은 암초, 타워 밑에 모래섬). 3단계 이름은 협곡에서 바다로 바꿨고, 저장 기록 호환을 위해 id `canyon`은 유지한다.

### 5.5 기록

맵별로 클리어 여부, 최고 웨이브, 남은 생명 기준 별 1~3개를 저장한다.

## 6. 화면과 조작

### 6.1 화면 배치

- 캔버스는 가로세로 비율을 유지하며 화면에 맞게 줄어든다.
- 세로 화면(폰): 위에 정보 바(생명, 골드, 웨이브), 가운데 맵, 아래에 동물 선택 패널.
- 가로 화면(PC): 패널이 맵 오른쪽에 온다.
- 정보 바에 일시정지와 배속(1x, 2x) 버튼이 있다.

### 6.2 조작

> 2026-10-26: 동물을 골라 칸을 누르는 설치 방식은 11절의 소환 버튼과 드래그 합성으로 바뀌었다.

마우스와 터치를 같은 방식으로 처리한다.

1. 아래 패널에서 동물을 누르면 선택된다. 골드가 모자라면 흐리게 표시되고 선택되지 않는다.
2. 맵의 빈 칸을 누르면 설치된다. 선택 중에는 설치 가능한 칸이 밝게 표시되고, 사거리가 원으로 미리 보인다.
3. 설치된 동물을 누르면 정보창이 뜬다: 사거리, 능력치, 업그레이드(비용 표시), 판매.
4. 빈 곳을 누르면 선택이 해제된다.

PC 보조 단축키: 1~5로 동물 선택, 스페이스로 일시정지, ESC로 선택 해제. 모바일에서는 화면 확대와 스크롤이 게임 조작을 방해하지 않도록 막는다.

### 6.3 메뉴

- 시작 화면에서 맵 3개를 고른다. 잠긴 맵은 자물쇠로 표시하고, 열린 맵에는 최고 기록(별, 최고 웨이브)이 보인다.
- 승리나 패배 시 결과창에서 다시 하기와 맵 선택으로 갈 수 있다.

### 6.4 광고 자리

게임 화면 안에는 광고를 넣지 않는다. 맵 선택 화면과 결과창 아래에만 자리를 비워 둔다. 실제 광고 코드는 이번 범위에 넣지 않는다.

## 7. 저장과 오류 처리

- `localStorage`의 키 하나(`td-save-v1`)에 JSON으로 저장한다: 열린 맵, 맵별 최고 웨이브, 별 개수.
- 저장 데이터가 깨졌거나 읽을 수 없으면(시크릿 모드, 저장 차단) 기본값으로 시작하고 게임은 그대로 돌아간다. 저장이 안 된다는 안내만 작게 보여준다.
- 버전 번호를 넣어 두어, 구조가 바뀌어도 이전 기록을 옮길 수 있게 한다.
- SVG를 불러오지 못하면 해당 동물을 이모지로 대신 그린다.
- 화면 크기가 바뀌거나 탭이 백그라운드로 가면 자동 일시정지하고, 돌아오면 시간 점프 없이 이어간다.

## 8. 테스트

`node --test`로 `core/`와 `data/`만 검사한다. 외부 패키지는 쓰지 않는다.

- 경로 위 위치 계산, 설치 가능 칸 판정
- 타워 목표 선택(가장 앞선 적), 사거리 안팎 판정, 연사 간격
- 피해 계산: 방패병 피해 감소, 독 지속 피해, 감속 효과, 분열체 쪼개짐
- 골드와 생명 변화, 판매 환급 70%, 업그레이드 비용과 한도
- 웨이브 스케줄: 모든 맵과 웨이브가 정의되어 있는지, 보스가 5, 10, 15번에 나오는지
- 데이터 점검: 맵 경로가 끊기지 않았는지, 설치 칸이 경로와 겹치지 않는지, 모든 수치가 양수인지
- 저장 데이터가 깨졌을 때 기본값으로 돌아가는지

화면 렌더링과 터치 조작은 자동 테스트가 어려우므로, 구현 후 Playwright로 브라우저를 열어 직접 눌러 보며 확인한다.

## 9. 배포

- 새 저장소에 올리고, `master` 푸시 시 GitHub Actions가 테스트를 통과한 경우에만 GitHub Pages로 배포한다. 기존 무료 도구 사이트와 같은 방식이다.
- 주소는 `luneeest-lang.github.io/<저장소 이름>/`이다.
- 기존 사이트에는 나중에 링크 한 줄만 추가한다. 이번 범위에는 넣지 않는다.

## 10. 열린 사항

- 새 저장소의 이름과 공개 여부는 아직 정하지 않았다. 구현 시작 전에 정하고, 만들기 전에 확인받는다.
- 이 설계 문서는 새 저장소가 생기면 그쪽으로 옮긴다.

## 11. 랜덤 소환과 합성 (2026-10-26 변경)

골드로 원하는 동물을 사서 놓고 골드로 업그레이드하던 방식을 바꿨다.

- **소환:** [소환] 버튼(PC는 `S`)을 누르면 5종 중 하나가 같은 확률로 나와, 길 바로 옆(대각선 포함 1칸) 빈 칸 중 무작위 위치에 아기 단계로 놓인다. 길에서 먼 칸은 사거리 밖이라 제외했다.
- **비용:** 첫 소환 50골드, 소환할 때마다 +5골드. 골드가 모자라거나 소환할 칸이 없으면 버튼이 꺼진다. 시작 골드는 150에서 200으로 올렸다(초반 3마리).
- **합성:** 타워를 끌어 같은 동물·같은 단계 타워 위에 놓으면, 놓인 자리의 타워가 한 단계 성장하고 끌어온 타워는 사라진다. 아기+아기→청년, 청년+청년→성체, 성체+성체→각성. 각성은 더 합칠 수 없다. 끄는 동안 합칠 수 있는 타워가 빛난다. 빈 칸이나 다른 타워 위에 놓으면 제자리로 돌아간다(이동 없음).
- **각성 모습:** 성체에 왕관을 쓰고 속성 색 오라가 생긴다.
- **판매:** 타워를 탭하면 정보창이 뜨고 판매만 할 수 있다. 환급은 그 타워에 들어간 소환 비용 합계(합성 재료 포함)의 70%(내림).
- **성장 수치:** 한 단계마다 공격력과 독 피해 ×2.2(재료 두 개보다 강하게), 공격 간격 ×0.9, 사거리 +0.25, 감속 배율 ×0.85(하한 0.3).
- **밸런스 점검:** 돈이 되면 소환하고 짝이 생기면 바로 합치는 단순 자동 플레이로, 맵마다 시드 20개 기준 승률 70~90%, 한 판 약 9~10분.

## 12. 웨이브 구성, 쉬는 시간, 세로 화면 (2026-10-26 변경)

- **웨이브마다 20마리:** 모든 웨이브는 보스를 포함해 정확히 20마리다(분열체가 죽으며 생기는 작은 슬라임은 제외). 구성은 `js/core/waves.js`의 표로 정한다. 새 적이 처음 나오는 웨이브(달리기 3, 분열체 4, 탱크 6, 방패병 8, 보스 5·10·15)는 그대로다.
- **쉬는 시간:** 스폰이 끝나고 필드의 적을 모두 처리하면(처치 또는 통과) 10초 카운트다운 뒤 다음 웨이브가 시작된다. 적이 남아 있는 동안에는 카운트다운이 없다. 버튼(⏭ 바로 시작)으로 건너뛸 수 있고, 남은 초만큼 보너스 골드를 받는다. 첫 웨이브도 10초 뒤에 시작한다.
- **난이도:** 마릿수가 줄어든 만큼 웨이브마다 적 체력 증가율을 20%에서 30%로 올렸다. 자동 플레이(건너뛰기 없음) 기준 맵마다 승률 75~90%, 한 판 약 13~14분이다. 건너뛰기를 쓰면 짧아진다.
- **세로 화면:** 화면이 세로이면 맵을 90도 돌려 세로로 길게(10×16칸) 보여준다. 폭 390px 폰에서 한 칸이 약 24px에서 39px로 커진다. 맵의 왼쪽(적이 나오는 곳)이 화면 위쪽이다. 동물, 몬스터, 나무, 암초, 바위, 집은 화면 기준으로 똑바로 세워 그린다. 터치 좌표는 `js/ui/input.js`의 `screenToCell`이 같은 규칙으로 되돌린다.

## 13. 보스 웨이브 (2026-10-26 변경)

- 보스 웨이브(5, 10, 15)에는 보스 1마리만 나온다. 나머지 웨이브는 20마리 그대로다.
- 보스 웨이브가 시작되면 3초(`BOSS_INTRO`) 동안 화면 가운데에 BOSS 경고를 띄우고, 경고가 끝나면 보스가 나온다. 화면 가장자리가 핏빛으로 어두워지며 심장박동처럼 맥동하고, 공포풍 글꼴(Google Fonts `Creepster`, 없으면 굵은 기본 글꼴)의 핏빛 글자가 깜빡이며 떨린다. 아래에 "무언가 다가온다…"가 나온다. 경고 중에도 클릭과 드래그는 그대로 된다. 움직임 줄이기 설정에서는 떨림과 깜빡임을 끈다.
- 보스 웨이브에서 받는 골드가 1마리분으로 줄어 보스 처치 보상을 100에서 200으로 올렸다. 자동 플레이 기준 맵마다 승률 70~75%이고, 진 판은 대부분 12~14웨이브다.

## 14. 효과와 연출 (2026-10-26 추가)

효과 상태(종류, 수명, 개수 상한 400개, 흔들림·번쩍임 세기)는 `js/ui/effects.js`에 화면과 분리해 두고 테스트한다. 그리기는 `render.js`가 한다. 규칙 쪽 이벤트에는 맞은 적(`targetId`), 처치한 적 종류와 보상, 집 도착(`leak`)을 담는다.

- **공격:** 동물마다 다른 발사체가 0.18초 동안 날아간다. 다람쥐는 도토리, 코끼리는 돌덩이와 충격파 고리, 펭귄은 얼음 조각, 독수리는 금빛 궤적, 뱀은 독 방울이다.
- **피격:** 맞은 몬스터가 0.09초 동안 하얗게 번쩍인다(미리 구운 흰 실루엣).
- **처치:** 몬스터 색의 픽셀 파편이 튀어 화면 아래로 떨어지고, 금색 보상 숫자(+5 등)가 떠오른다. 보스는 파편이 더 많고 붉은 고리와 화면 흔들림이 있다.
- **집 도착:** 화면 가장자리가 붉게 번쩍이고 상단 생명 숫자가 흔들린다. 골드가 늘면 골드 숫자가 살짝 커진다.
- **소환:** 하얀 고리와 반짝임이 생긴다.
- **합성:** 금빛 고리와 파편, "성장!" 문구가 나온다. 각성 때는 더 큰 폭발, "각성!" 문구, 약한 화면 흔들림이 있다.
- 세로 화면에서도 글자와 파편은 화면 기준으로 그린다. 동작 줄이기 설정에서는 화면 흔들림과 숫자 애니메이션을 끈다.

## 15. 소환 비용 변경 (2026-10-26)

플레이해 보니 어렵다는 의견에 따라, 소환할 때마다 +5골드 오르던 비용을 웨이브 구간으로 바꿨다. 소환 횟수와 상관없이 1~5웨이브 50골드, 6~10웨이브 55골드, 11~15웨이브 60골드다(`CONFIG.summonStep`, `summonStepWaves`). 자동 플레이 기준 세 맵 모두 20판 전승, 이길 때 남은 생명 평균 약 19개, 한 판 약 10~11분으로 쉬워졌다.

## 16. 돌산 맵, 웨이브 보너스, 체력 상향 (2026-10-26)

- **1단계 맵 → 돌산:** 테마를 `mountain`으로 바꾸고 이름을 '초원'에서 '돌산'으로 바꿨다(저장 기록 호환을 위해 id `meadow`는 유지). 회갈색 바위 바닥(갈라진 틈, 자갈, 드문 풀포기와 이끼), 밝은 자갈 산길, 장애물은 픽셀 바위다. 초원 그리기 코드는 쓰는 맵이 없어 지웠다.
- **웨이브 클리어 보너스:** 웨이브의 적을 모두 처리하면(마지막 웨이브 포함, 웨이브마다 한 번) 10골드를 주고 맵 가운데에 "웨이브 클리어 +10"을 띄운다(`CONFIG.waveClearBonus`).
- **몬스터 체력 5% 상향:** 모든 몬스터 체력에 1.05를 곱한다(`HP_BONUS`).
- 자동 플레이 기준 결과는 이전과 비슷하다(세 맵 모두 20판 전승, 남은 생명 평균 18~19개, 한 판 약 10~11분).

## 17. 맵 이름, 체력바, 데미지 숫자 (2026-10-26)

- **맵 이름:** 초급(돌산), 중급(숲), 고급(바다). id는 그대로다.
- **체력바:** 몬스터 머리 위에 두꺼운 빨간 바(칸의 약 16% 두께, 최소 5px)를 어두운 테두리·배경과 함께 그린다.
- **데미지 숫자:** 규칙 쪽이 맞은 적마다 실제로 들어간 피해량을 `hit` 이벤트(`enemyId`, `amount`, 위치)로 내보내고, 화면은 노란 숫자(반올림, 최소 1)를 0.65초 동안 띄운다. 방패병은 절반, 보스는 독수리 1.5배처럼 실제 값이 나온다. 독 지속 피해는 숫자가 너무 많아져서 띄우지 않는다. 보상 숫자(+골드)는 주황빛 금색으로 구분한다.
